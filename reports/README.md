## 共同结论

| 维度 | 游戏 | 微短剧 |
|---|---|---|
| 市场状态 | 6.84 亿用户，存量经营；小游戏和多端增长 | 近 7 亿用户，供给爆发；进入强监管和精品化 |
| 建议主战场 | 存量促活、跨端续玩、试玩转化、增量归因 | 合规接入、继续观看、跨端续播、透明结算 |
| 明确不打 | 自研重度游戏、复制社交/内容流、抢自然量归因 | 自建制片、囤 IP、封闭 App、投流套利 |
| 用户北极星 | 月度增量高质量游玩用户 | 月度增量有效观看用户 |
| 伙伴价值平衡结果 | 每千名合格用户的伙伴成熟净应结算增量 iNSPM | 每千名合格用户的伙伴成熟净应结算增量 iNSPM |
| 平台持续性平衡结果 | 滚动 90 日正增量 ROI 活跃伙伴数 | 滚动 90 日正增量 ROI 活跃伙伴数 |
| 核心数据方法 | 稳定随机留白，区分自然量、归因量和实验增量 | 稳定随机留白，分离播放、广告、支付和结算 |
| 硬护栏 | 版号、未保、支付、隐私、投诉 | 资质、编号、版权、付费、未保、内容与广告 |

## 共同指标原则

```text
业务北极星（用户因果增量）+ 伙伴价值 + 平台持续性
   ↓
B1—B10 十个标量核心指标 + B11 一组不可加总发布护栏
   ↓
运营与健康支撑（接入、性能、漏斗、结算、质量、合规）
```

1. DAU、GMV、播放和下载不能直接代表服务分发贡献。
2. 报表归因只能说明触点关系，随机实验才回答“没有该分发会少多少”。
3. 订单、支付、结算、收入和利润必须分开建模。
4. 非公开华为数据均保留为内部回填项，不使用外部均值伪装基线。
5. 100 元流向中的假设用于模式比较，不代表真实合同、税务或会计处理。
